\section{Objectives}
\begin{enumerate}
  \item To demonstrate the four properties of a class: abstraction, encapsulation, inheritance, and polymorphism.
  \item To implement an abstract \texttt{Sensor} base class and derived concrete sensor classes.
  \item To show encapsulation through private sensor values and public setter/getter methods.
  \item To show runtime polymorphism using a base-class pointer array.
  \item To explain how each part of the code reflects a class property.
\end{enumerate}
