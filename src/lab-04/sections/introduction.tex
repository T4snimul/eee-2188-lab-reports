\section{Introduction}
\markright{Introduction}
This experiment presents a sensor system implemented in C++ that demonstrates the four main properties of a class: abstraction, encapsulation, inheritance, and polymorphism; an abstract base class named \texttt{Sensor} defines a common interface and hides implementation details while derived classes such as \texttt{TemperatureSensor} and \texttt{DistanceSensor} provide specific behavior, with abstraction shown by the base \texttt{Sensor} class and its pure virtual method, encapsulation enforced by keeping sensor values private and exposing controlled access methods, inheritance realized by deriving concrete sensor types from the abstract base class, and polymorphism exercised by using a base-class pointer array to call \texttt{display()} at runtime.
