\section{Conclusion}
\markright{Conclusion}

The lab demonstrated the four core properties of a class in C++: abstraction, encapsulation, inheritance, and polymorphism. The abstract \texttt{Sensor} class provided a reusable interface, while derived classes for temperature and distance encapsulated their own data and behavior. Using a \texttt{Sensor*} array to call \texttt{display()} showed runtime polymorphism and made the code flexible for future sensor types. Overall, the experiment reinforced how class properties help structure code, reduce duplication, and support maintainable designs.
