\section{Introduction}
\markright{Introduction}
Java is one of the most widely used programming languages for software development, web applications, and general-purpose problem solving. This experiment introduces the basic structure of a Java program and demonstrates how simple programming concepts such as output, input, loops, and conditional statements are used to solve real problems. The first program prints a message to the console to verify the Java environment and show the structure of a class and main method. The second program reads an integer from the user and checks whether it is a prime number using repetition and decision-making logic.

By completing these tasks, students learn the fundamental syntax of Java, how to compile and run programs, and how to translate an algorithm into executable code. The experiment also helps establish a strong foundation for later topics such as object-oriented programming, functions, and data structures.
