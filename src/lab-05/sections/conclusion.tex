\section{Conclusion}
\markright{Conclusion}

This laboratory introduced the basic concepts of Java programming through two simple but important programs. The first program showed how a Java class is written and how output is displayed in the console, while the second program demonstrated how to use input, loops, and conditional statements to solve a real computational problem. These examples helped connect programming theory with practical implementation and showed how even small programs can express meaningful logic.

The experiment also emphasized the importance of understanding program structure, syntax, and flow of execution in Java. Through writing and running the programs, students gained confidence in using variables, user input, arithmetic operations, and decision-making statements. Overall, the lab provided a strong foundation for learning more advanced Java concepts in future assignments and projects.
