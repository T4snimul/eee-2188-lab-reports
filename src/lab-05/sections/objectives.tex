\section{Objectives}
\begin{enumerate}
  \item To understand the basic structure of a Java program and the role of the \texttt{main()} method.
  \item To write and execute a simple Java program that prints output to the console.
  \item To learn how Java uses classes, methods, and statements to perform tasks.
  \item To read user input using the \texttt{Scanner} class and process numeric data.
  \item To apply loops and conditional statements to solve a prime number checking problem.
\end{enumerate}
