\section{Conclusion}
\markright{Conclusion}

This experiment provided a solid foundation in C++ by demonstrating fundamental I/O operations. The first problem introduced basic console output with \texttt{std::cout}, while the second problem covered user input using \texttt{std::cin} with character arrays. A key observation from this approach is the limitation of \texttt{std::cin}, as it fails to capture any input after a whitespace character. This experience highlights the importance of selecting appropriate methods for handling different types of user input in C++ programming and reveals a potential pitfall of using \texttt{std::cin} for string-based data.
