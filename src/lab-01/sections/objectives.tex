\section{Objectives}
\begin{enumerate}
    \item To understand the basic syntax and structure of a C++ program.
    \item To learn how to use the \texttt{cout} stream to print text to the console.
    \item To learn how to use the \texttt{cin} stream to read user input.
    \item To become familiar with compiling and running simple C++ programs.
\end{enumerate}
