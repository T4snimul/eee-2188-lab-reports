\section{Objectives}
\begin{enumerate}
  \item To understand the concept of classes and objects in C++.
  \item To learn how to define a class with member variables and member functions (methods).
  \item To implement constructors to initialize object state upon creation.
  \item To understand the role of destructors in object lifecycle management.
  \item To practice creating and manipulating multiple objects of a class.
  \item To encapsulate data and functionality within a class to model real-world problems.
\end{enumerate}
