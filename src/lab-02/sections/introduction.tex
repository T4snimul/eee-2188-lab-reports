\section{Introduction}
\markright{Introduction}

This experiment transitions from procedural programming to the fundamentals of Object-Oriented Programming (OOP) in C++. It focuses on the core concepts of classes and objects. Through a series of problems, the experiment demonstrates how to define classes to model real-world entities, encapsulate data and behavior, and manage the lifecycle of objects using constructors and destructors. The problems involve creating a \texttt{Student} class to manage student records, a \texttt{Book} class to observe object creation and destruction, and a \texttt{Motor} class to perform encapsulated calculations.
