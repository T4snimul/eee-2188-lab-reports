\section{Conclusion}
\markright{Conclusion}

This experiment provided practical experience with the fundamental principles of Object-Oriented Programming in C++. The implementation of the \texttt{Student} class demonstrated how to effectively group related data and functions to model a real-world entity. The \texttt{Book} class provided a clear illustration of an object's lifecycle, with constructors and destructors automatically managing initialization and cleanup. Finally, the \texttt{Motor} class showcased the power of encapsulation by bundling data (voltage, current) with methods that operate on that data (power, resistance calculations), creating a self-contained and reusable component. Collectively, these problems highlight the advantages of using classes for creating structured, modular, and maintainable code.
