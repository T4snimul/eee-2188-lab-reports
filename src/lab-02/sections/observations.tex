\section{Observations}
\markright{Observations}

The diode current was calculated from the voltage drop across the series resistor:
\[
  I_D = \frac{V_S - V_D}{10\,\text{k}\Omega}
\]
For both forward and reverse bias, the current is reported in mA.

The observation section records the measured diode voltage together with the corresponding
current for each supply setting. These values were then plotted to show how the diode
responds when the bias is changed gradually in either direction.

The forward-bias data show the familiar rise in current as the applied voltage increases.
The current remains small at first because the diode has not yet reached the point where
the barrier is sufficiently reduced, but it increases steadily once conduction begins.
This trend is visible in the table values and becomes clearer in the graph that follows.

The reverse-bias readings remain effectively zero on the meter scale used in the lab.
This is expected because the diode blocks current in reverse bias and only a tiny leakage
current flows under normal operating conditions. The recorded values therefore confirm
that the diode behaves almost like an open circuit for the reverse-bias range used here.

Taken together, the forward and reverse results show the asymmetric behavior of the
silicon p-n junction diode. The diode conducts more readily in forward bias, while the
reverse-bias current remains too small to be distinguished clearly with the measurement
range used in this experiment.
